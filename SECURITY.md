# Security policy

## Supported versions

Only the latest release of Unused Data Blocks Detector receives fixes. It supports Blender 5.3.

## Reporting a problem

If you find a security problem, for example something that could make Blender delete data you didn't choose, or run unexpected code, **please don't open a public issue.**

Report it privately instead: go to the repository's **Security** tab and choose **Report a vulnerability** ([direct link](https://github.com/mttfntn/unused-data-blocks-detector-blender/security/advisories/new)).

Please describe the problem and how to reproduce it. You'll get a reply as soon as possible, and the fix will be released before the details are made public.
